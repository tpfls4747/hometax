# 삼쩜삼 리디자인 — 연말정산 미리보기 · 환급/납부 절감 추천

## 프로젝트 소개
삼쩜삼 연말정산 미리보기 화면에 아래 기능을 추가하는 팀 프로젝트입니다.

1. **현재 예상 금액 안내** — 지금 기준으로 내가 *환급받을* 금액 / *추가 납부(뱉어낼)* 금액
2. **절감 방법 추천** — 현재 상태에서 추가 납부액을 줄이거나 환급액을 늘리는 방법 제안
   (예: 신용카드 → 체크카드 비중 조정, 연금저축/IRP 납입, 의료비·교육비·기부금 공제, 월세 공제 등)
